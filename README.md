# Landing Page Psicologia

Este repositório contém a landing page de apresentação de um psicólogo, desenvolvida em HTML.

Objetivo

- Mostrar um exemplo de página institucional/portfolio para pacientes e clientes.

Como visualizar

1. Clone ou baixe o repositório.
2. Abra o arquivo `index.html` no seu navegador.
